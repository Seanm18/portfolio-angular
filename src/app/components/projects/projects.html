Sistema de Análisis de Sentimiento para Reseñas con NLP

Desarrollé un sistema que clasifica automáticamente reseñas de productos como positivas, negativas o neutrales usando Procesamiento de Lenguaje Natural (NLP). El sistema procesa datasets completos de una sola vez, analiza la polaridad de cada reseña y genera una visualización de la distribución de sentimientos. Aplicado a un dataset de 20 reseñas logrando una clasificación precisa con resultados de 10 positivas, 7 negativas y 3 neutrales. Este tipo de solución es utilizada por empresas para analizar miles de reseñas de clientes automáticamente, identificando patrones y apoyando decisiones de negocio basadas en retroalimentación real.

Python NLP pandas matplotlib TextBlob
